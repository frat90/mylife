# My Life OS — Premium PWA

Versione grafica mobile-first di My Life OS.

Moduli: Dashboard, Money, Trading, Auto, Food & Wine, Forma, Obiettivi.

I dati sono locali nel browser tramite localStorage. Sono inclusi backup/ripristino JSON e service worker per l'uso offline.

## GitHub Pages
1. Crea un repository.
2. Carica tutti i file e la cartella `icons`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Apri l'URL sul telefono e installa la PWA dalla voce del browser "Aggiungi alla schermata Home" / "Installa app".

Nota: il service worker richiede HTTPS; GitHub Pages lo fornisce.
