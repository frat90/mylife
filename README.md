# My Life OS
PWA locale per Dashboard, Money, Trading, Auto, Food & Wine, Forma e Obiettivi.

## GitHub Pages
Carica tutti i file nel repository, poi Settings → Pages → Deploy from a branch → main → /(root).
Apri il sito dal telefono e installalo dalla schermata del browser.

I dati restano nel browser tramite localStorage. Usa Backup/Ripristina per conservarli.
